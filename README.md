### 【ゲーム概要】
自動生成される迷路を進み、青いスタート地点から赤いゴール地点を目指すゲームです。ゴールに到達するとクリアになります。

### 【操作方法】
上下左右の矢印キー：プレイヤーを移動
スペースキー：クリア後に新しい迷路を生成して再スタート
【ダウンロードと初回起動】

### ダウンロード・起動方法
1. https://github.com/Seiya0106/maze/releases/tag/v1.0.0 からZIPファイルをダウンロードします。
2. ZIPファイルをダブルクリックして展開します。
3. 展開したフォルダ内の「Game.app」を開きます。
4. macOSに「開発元を確認できないため開けません」などと表示された場合は、一度「完了」または「キャンセル」を選びます。
5. Appleメニューから「システム設定」→「プライバシーとセキュリティ」を開きます。
6. 下へスクロールし、このアプリについて表示されている「このまま開く」を選びます。
7. 確認画面でもう一度「開く」を選びます。
